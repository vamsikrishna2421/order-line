# Order Line

One-page marketing site for Order Line, an AI phone assistant for restaurants: it answers every call, takes takeout orders in plain conversation, and sends them to the kitchen.

The page explains the product and invites restaurants to email about a pilot. It does not contain the phone assistant itself.

## Stack

A single `index.html` with inline CSS: no JavaScript framework, no build step, no dependencies. Light and dark themes follow the system setting.

## Run it

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

## Deploy

Publish the repo root on any static host. GitHub Pages is enabled for this repo.
